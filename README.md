# PitWall

Landing page estática inspirada no ambiente de Fórmula 1, com foco no GP de São Paulo e na experiência de compra de ingressos para o autódromo de Interlagos.

## Visão geral

Este projeto foi desenvolvido em HTML e CSS para simular uma página promocional de corrida com:

- hero section com destaque para o GP de São Paulo
- grid de pilotos
- tabela de classificação
- seção de ingressos com formulário
- layout responsivo para desktop e mobile

## Estrutura do projeto

```text
PitWall/
├── index.html
├── styles.css
├── img/
│   └── piloto.jpg
└── README.md
```

## Tecnologias utilizadas

- HTML5
- CSS3
- Fontes externas do Google Fonts

## Como executar

Você pode abrir o arquivo `index.html` diretamente no navegador.

Ou, se preferir utilizar um servidor local, execute:

```bash
cd PitWall
python -m http.server 8000
```

Depois acesse:

```text
http://localhost:8000
```

## Observações

- O conteúdo da página é ilustrativo e foi criado com fins de estudo.
- Os dados de classificação e preços são fictícios, apenas para composição visual.
- A imagem principal da página está em `img/piloto.jpg`.
